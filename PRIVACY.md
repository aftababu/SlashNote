# SlashNote Privacy

## Zero Telemetry

SlashNote does not collect telemetry.

The application does not intentionally collect or transmit:

- note contents
- filenames
- local paths
- search queries
- editing activity
- usage statistics
- crash reports
- device identifiers
- advertising identifiers
- location
- behavioral analytics

## Network Communication

SlashNote may communicate over the network only when required for
user-facing functionality, including:

- Git synchronization with a user-configured remote
- application update checks
- application update downloads

These operations are not used for behavioral analytics.

## Crash Reporting

SlashNote does not automatically transmit crash reports.

## Analytics

SlashNote does not integrate analytics or behavioral tracking services.

## Data Storage

Notes are stored locally as Markdown files.

SlashNote does not require a SlashNote account or SlashNote-hosted
storage service for normal note-taking.
